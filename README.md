

# Welcome to my LeagueTeamBuilder

<p>This was inspired by all the times I would be in discord with friends and suddenly we would have more than 10 people in one call. Which woud lead us to play an inhouse custom 5v5 game. The process of making teams was always tedious as we woukd either pick captains or do some sort of randomization. Out of this ritual my idea for this tool/software was created</p>

<p>The goal was to make a **simple easy to use program** that I could run on my computer and also give to my friends so that any of use could use it</p>

<p>As I built the tool, I started to add more features that I found fun or interesting.</p>

## What it is

<p>League Team Builder is a python based windows application with the following features</p>
-Ability to enter ten IGN's(__In Game Names__) and randomize them into two teams of 5. Each player is assigned a portrait
-Ability to select random champions for each player
-Can pull latest data from OP.GG which provides champions by role, as well as win rate and play rate
-Filters for randomizing champions based on the play rate and win rate
-Additional __'rolls'__ for randomizing champion more than once
-Arena Game mode randomizer, up to 16 players(8 teams of 2) but works with any number less than or equal to 16

## How to use?

>Simply run the **build.bat** file and then run the executable file after it is created
